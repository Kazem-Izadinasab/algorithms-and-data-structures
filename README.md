# Algorithms and Data Structures

A collection of implementations and practice problems covering fundamental data structures, algorithms, and problem-solving techniques.

## Languages
- Python
- C++

## Topics

1. Complexity Analysis
2. Arrays and Strings
3. Linked Lists
4. Stacks and Queues
5. Hash Tables
6. Trees and Binary Search Trees
7. Heaps and Priority Queues
8. Graphs
9. Recursion and Backtracking
10. Sorting and Searching
11. Greedy Algorithms
12. Dynamic Programming

## Repository Structure

Problems are organized by topic. Each implementation includes, where applicable:
- Problem description and source
- Solution approach
- Time complexity
- Space complexity
- Implementation
